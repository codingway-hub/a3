# a3 v1.0 一期实施计划（M1-M4）

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. 里程碑边界（M1/M2/M3/M4 结束处）必须暂停向用户汇报并获确认。

**Goal:** 落地 a3 v1.0——Go 终端采集器（Core + plugin-claude）+ Gin 服务端 + Vue3 审计后台 + Docker Compose 部署，实现 ClaudeCode 日志审计与 Hook 拦截闭环。

**Architecture:** 终端与服务端共享唯一契约 `pkg/schema`；终端为编译期注册插件架构（Core 骨架 + plugin-claude 差异化全量实现）；服务端零 Agent 定制，仅消费标准事件；存储 PG 必选、ClickHouse/MinIO 仅预留接口位。

**Tech Stack:** Go 1.26（gin、pgx/v5、fsnotify、cobra、golang-jwt/v5、google/uuid、testify）、Vue3 + Vite + Element Plus + Pinia + axios、PostgreSQL 16、Docker Compose。

**参照文档：** `docs/plans/2026-08-22-v1.0-implementation-design.md`（实现级设计，本文的上级依据）。

**已验证的真实日志事实（解析器依据）：**
ClaudeCode 会话文件 `~/.claude/projects/<munged-cwd>/<session-uuid>.jsonl` 每行一个 JSON。关键行型：
- `user` 行：`{type:"user", uuid, sessionId, timestamp, cwd, version, gitBranch, isMeta, isSidechain, message:{role:"user", content: string | [item...]}}`
- `assistant` 行：同上结构，`message.content` 为数组，item 有 `{type:"text",text}` 与 `{type:"tool_use",id,name,input}`
- user 的 content 数组中 item 有 `{type:"tool_result",tool_use_id,content,is_error}`
- 噪音行型（丢弃）：`attachment`、`queue-operation`、`file-history-snapshot`、`file-history-delta`、`atis-latch`、`last-prompt`
- `system` 行（含 local_command stdout）：映射为 conversation/role=system

**全局约定：**
- module：`github.com/codingway-hub/a3`；工作分支 `feat/v1-mvp`
- 测试库约定：`TEST_DATABASE_URL`（默认 `postgres://a3:a3@127.0.0.1:5433/a3_test?sslmode=disable`），不可达时集成测试 `t.Skip`

### Task M2-9: preToolUse Hook 拦截（TDD）

**Files:** Create `internal/agent/plugins/claude/hook.go`, `hook_test.go`

协议（ClaudeCode 原生）：stdin JSON `{"session_id":..., "tool_name":..., "tool_input":{...}}`；判定：
- 命中 block 规则 → stderr 中文原因（含规则名+脱敏 snippet）→ **exit 2**（阻断）
- 仅命中 alert 规则 → 组装 risk 事件（EventID=uuidv5(ns, session+tool+input)、SourceMethod=hook、RiskTags）交上行队列 → exit 0
- 无命中 → exit 0
- hook 路径**不产生常规审计事件**（file_log 路天然覆盖，避免双份重复）

测试：stdin 注入 `{"tool_name":"Bash","tool_input":{"command":"rm -rf /"}}` → exit 2 + stderr 含"已拦截"；安全命令 → exit 0。

**Commit:** `feat(plugin-claude): preToolUse 前置毫秒级拦截`
