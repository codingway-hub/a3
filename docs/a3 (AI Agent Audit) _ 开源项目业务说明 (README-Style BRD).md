# a3 \(AI Agent Audit\) \| 开源项目业务说明 \(README\-Style BRD\)

## 1\. 项目简介 \(Intro\)

**a3 \(****AI Agent Audit****\)** 是一款**通用、可插拔、全生态适配**的终端 AI 编码 Agent 审计开源工具。

当前 ClaudeCode、Codex、Trae、Kilo、OpenCode、Cline 等 AI 编码 Agent 层出不穷，但行业内没有一款**统一通用**的开源审计方案：各个工具日志格式、行为模型各不相同，现有开源工具均为「单工具专属」，无法快速适配新 Agent，企业和团队只能零散自建脚本或依赖闭源商业产品。

本项目旨在填补开源空白，打造**一次部署、全品类 AI 编码 Agent 永久纳管**的通用审计基座，面向个人开发者、研发团队、中小企业提供轻量化、无侵入、可扩展的 AI 终端安全审计与主动防护能力。

## 2\. 行业现存问题 \(Problems\)

目前全球开源生态针对「本地 AI 编码 Agent 安全审计」存在明显短板，所有团队都会面临以下问题：

- **工具碎片化，无统一标准**：各类 AI 编码 Agent 日志路径、字段结构、工具调用协议完全不统一，没有通用解析与审计框架。

- **现有工具强绑定单一 Agent**：市面上所有开源审计工具均针对某一款 Agent 开发，出新工具就要换新系统，无法长期迭代。

- **本地行为黑盒不可见**：AI Agent 可自主执行 Shell、读写代码、强制 Git 推送、操作数据库，终端行为无统一留存、无回放、无追溯。

- **敏感数据泄露无感知**：开发者将私有代码、密钥、配置上传大模型，无 DLP 审计、无风险记录，极易引发数据泄露。

- **中小企业无低成本合规方案**：商业 AI 安全网关价格高昂，零散脚本不稳定、不可维护，缺少开箱即用的开源合规审计方案。

- **新工具迭代快，适配成本极高**：每年大量新型编码 Agent 诞生，传统方案需要重构代码、改存储、改前端，适配效率极低。

## 4\. 核心业务目标 \(Goals\)

本开源项目聚焦「AI 终端行为审计、安全观测与高危行为主动拦截」核心能力，专注垂直场景、功能聚焦、不臃肿、不堆砌无关能力：

1. **通用适配，无限扩展**：采用插件化架构，新增 AI Agent 无需重构主程序，仅需编写适配插件，彻底解决工具碎片化问题。

2. **全量会话可回放**：统一采集、标准化解析所有 Agent 的对话记录、工具调用、Shell 执行、文件读写行为，支持完整会话回放与溯源。

3. **安全审计\+主动防护**：内置通用 DLP 敏感检测、高危操作识别，支持自定义策略完成恶意行为**强制拦截、进程阻断**，兼顾观测与防护能力。

4. **开箱即用，低侵入**：不改变开发者使用习惯、不包装命令、无性能损耗、支持跨平台终端部署。

5. **开源合规友好**：提供标准化审计日志、导出能力，满足中小团队内部安全管控、基础合规留痕需求。

- **Community\-Driven**：开放插件贡献规范，共建全生态 Agent 适配库
