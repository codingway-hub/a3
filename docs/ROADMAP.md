# a3 路线图

> 期次边界依据《v1.0 一期落地技术方案》与历次实施计划整理；本文只记录「做没做、什么期做」，不含实现细节。

## 当前状态（截至 2026-08-30）

| 期次 | 状态 | 内容 |
| --- | --- | --- |
| **v1.0 一期** | ✅ 已完成 | Claude Code 专属采集插件（会话审计 + PreToolUse 拦截）、Codex 纯审计插件、规则中心（内置 14 条 + 自定义 CRUD/启停/热加载 + 版本化下发 + 三级降级回退）、告警中心、控制台（Vue3）、单机/团队两种部署 |
| **安全加固版（bug-fix，无期号）** | ✅ 已完成并验收（2026-08-30） | 验收门槛「接入安全 + 审计证据不丢失」：默认回环绑定 + 可选 TLS、自动注册默认关、同指纹轮换需旧 Token 凭证、控制台吊销即时生效、吊销后无凭证重建恢复路径、events 复合主键 `(device_id, event_id)`、入库同事务 + 启动对账、spool 三目录（incoming/working/quarantine）+ 隔离区 + 容量可配、上传分类处置（401 绝不烧库） |
| **规则操作级审计留痕（三期项提前）** | ✅ 已完成（2026-08-30） | `audit_log` 表 + `rules.updated_by`：规则 CRUD/启停与设备吊销/恢复全部同事务留痕（谁在何时改了什么、变更前后 JSONB 快照），失败路径不留痕；`GET /audit-log` 查询端点；控制台规则页「历史」对话框展示变更历史 |
| **一条命令安装（计划外提前）** | ✅ 已完成（2026-08-30） | 管理员 `install-server.sh <公开地址>` 一键装服务端（自动生成密钥口令/开放自助注册/非回环自动对外监听）；控制台公开「接入指南」页（`/setup-guide`）给用户一条 `curl <服务端>/install.sh \| sh` 完成采集器安装（下载→注册→Hook→launchd/systemd 常驻服务）；注册路径唯一化，接入叙事收敛为一种 |
| **告警通知外送 Webhook（三期项提前）** | ✅ 已完成（2026-08-31） | `A3_NOTIFY_WEBHOOK_URL` 配置即启用：独立 notify 包轮询未通知告警，每分钟聚合一条中文摘要推送到 Slack 兼容/企微/钉钉/飞书群机器人（四信封），失败指数退避 1min→15min、行级 10 次失败自然老化，at-least-once 语义（控制台为准）；存量告警不补送；控制台告警列表「已通知」标记 |

## 二期（候选，未启动）

存储与分析扩展，compose 已预留注释位：

- **ClickHouse**：海量事件分析加速（一期默认 PostgreSQL，预留接入适配层）
- **MinIO**：超大原始会话日志归档、导出文件对象存储
- **第三方 SIEM 对接**、**网络网关/流量劫持**、**网页端 AI 管控**（一期方案显式划出范围）

## 三期候选（明确推迟项）

来自历次计划「显式不做」与验收复盘：

- **RBAC**：管理员/审计员分角色权限
- **管理员失窃检测与告警通知闭环**（邮件外送仍推迟；Webhook 外送已于 2026-08-31 提前完成，见上表）
- **Codex 本地阻断**：等上游出现稳定 PreToolUse 类协议后评估接入（当前 Codex 插件纯审计）
- ~~**规则操作级审计留痕**~~：已于 2026-08-30 提前实施完成（见上表），设备吊销/恢复一并复用同一 `audit_log` 机制
